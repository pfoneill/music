# music

Music in ABC notation. To convert from ABC notation to sheetmusic in PDF form use the ["ABC Music Notation" VSCode extension](https://marketplace.visualstudio.com/items?itemName=softaware.abc-music).

## Quickstart

1. Open repo in VS Code.
2. Install the extension.
3. Open command pallet F1>>Show Preview to view sheetmusic.
4. F1>>Print to print sheetmusic.
